# 策略经典图形复评评分体系

本文档描述 AI 复评阶段的经典图形加分口径。量化初选负责硬条件，AI 复评先执行通用评分框架；如果策略声明了经典图形匹配环节，再叠加经典图形加分。

## 总原则

- 经典图形比对发生在 AI 复评阶段，不作为量化初选硬过滤。
- 经典图形专项规则只是在通用规则基础上叠加，不替代趋势、位置、量价、历史异动和风险判断。
- 是否启用五维评分由“经典图形匹配总开关 + 候选票来源策略是否有经典图形定义”共同决定，不由策略名是否为 B1/B2 决定。
- 当前已有经典图形定义的单一策略是 `b1`、`b2`、`brick`。
- 页面只提供一个经典图形匹配总开关；开启后，复评器按候选票自身 `strategy` 自动选择对应经典图形规则。
- 复合策略一定不启用经典图形匹配环节；策略名包含 `+`、`&`、`,`、`|` 等组合含义时按基础四维评分处理。
- 没有经典图形定义的单一策略，即使总开关开启，也按基础四维评分处理。
- 图形类别之间没有强弱顺序。B1 四类、B2 三类、砖型图反转原型都只表示结构原型。
- 符合任一类经典图形，并且 K 线形态、成交量、量价关系一致，才给经典图形加分。
- 不符合任一类经典图形，不给经典图形加分。
- 上涨放量、回调缩量是健康量价关系；下跌放量、最大量在阴线、放量冲高回落、连续放量滞涨都要扣分。

当前复评 JSON 保持兼容字段：`previous_abnormal_move` 仍保留“前期是否有有效资金异动”的通用含义，只评价成交量异动和资金进场痕迹。经典图形匹配单独输出并单独计分，不叠加进 `previous_abnormal_move`。

新增输出：

- `classic_pattern_type`
- `classic_pattern_reasoning`
- `scores.classic_pattern_match`

## 权重方案

未启用经典图形匹配环节的策略沿用通用四维权重：

| 维度 | 权重 |
| --- | --- |
| `trend_structure` | 20% |
| `price_position` | 20% |
| `volume_behavior` | 30% |
| `previous_abnormal_move` | 30% |

启用经典图形匹配环节的策略使用通用四维 + 经典图形五维权重：

| 维度 | 权重 |
| --- | --- |
| `trend_structure` | 20% |
| `price_position` | 20% |
| `volume_behavior` | 30% |
| `previous_abnormal_move` | 20% |
| `classic_pattern_match` | 10% |

代码层会根据策略是否启用经典图形匹配环节选择权重：启用时要求五个 score 字段并按五维权重重算，未启用或复合策略要求基础四个 score 字段并按四维权重重算，避免模型自己算错总分。

## 实施方案

1. Prompt 输出契约新增 `scores.classic_pattern_match`。
2. `previous_abnormal_move` 只保留原始成交量异动含义，不混入经典图形分。
3. 复评配置通过 `classic_pattern_enabled` 控制是否启用经典图形匹配总开关，默认开启。
4. 启用经典图形匹配环节的复评结果如果包含五个评分字段，复评器按 20% / 20% / 30% / 20% / 10% 重算总分。
5. 未启用经典图形匹配环节的策略、复合策略如果包含基础四个评分字段，复评器按 20% / 20% / 30% / 30% 重算总分，并把 `classic_pattern_match` 归零。
6. 结果中心展示 `classic_pattern_type` 和 `classic_pattern_match`，用于区分图形类别与匹配强度。

兼容说明：旧运行快照中的 `classic_pattern_strategies` 仍可读取；新配置和页面只写入 `classic_pattern_enabled`。

## 经典图形加分分档

| 分数 | 含义 |
| --- | --- |
| 5 | 高度符合某一类经典图形，K 线结构完整，位置清晰，上涨放量、回调缩量，信号日前后量价共同支持多头占优。 |
| 4 | 明确符合某一类经典图形，但有一处轻微瑕疵，例如位置略高、回调缩量不极致、上影线稍明显。 |
| 3 | 部分符合经典图形，有雏形但 K 线连续性、位置或量价配合不够充分，只给少量加分。 |
| 2 | 不属于任何经典图形，或图形过于普通；没有明显破坏，但不给经典图形加分。 |
| 1 | 不属于经典图形且存在破坏性结构，例如放量阴线、最大量下跌、明显出货、长上影失败、趋势断裂。 |
| 0 | 图表信息不足，无法判断经典图形匹配。 |

## B1 经典图形

### 第一类：低位起涨后缩量回踩

特征：

- 前期经历低位横盘、V 形修复或平台突破。
- 上涨阶段有明显放量，说明资金开始进场。
- 信号日前出现回踩，通常靠近知行趋势线或短期均线。
- 回调阶段缩量，说明抛压减弱，像健康洗盘。
- KDJ J 回到低位时，价格结构没有被破坏。

加分点：

- 突破或修复阶段放量清楚。
- 回踩不破关键支撑。
- 回调量明显低于上涨量。

扣分点：

- 回踩阶段放量下跌。
- 价格跌破主要支撑后没有修复。
- 前期上涨缺乏放量确认。

### 第二类：强异动后一波回调

特征：

- 前期出现放量强攻、快速拉升或明显异动。
- 随后进入横盘、阶梯式回撤或短线整理。
- 整理阶段成交量逐步收缩。
- 信号日价格仍在主要趋势支撑上方，趋势没有被破坏。

加分点：

- 强攻阶段最大量出现在上涨 K 线。
- 回调缩量，且没有连续放量阴线。
- 回撤深度可控，仍保留二波预期。

扣分点：

- 强异动后高位放量滞涨。
- 最大量出现在下跌 K 线。
- 反弹无量、下跌放量。

### 第三类：下跌后的右侧修复

特征：

- 左侧有较深下跌、长期弱势或明显套牢区。
- 右侧出现放量修复、突破平台或重新站回均线。
- 随后缩量回踩确认，底部逐步抬高。
- 信号日处于修复结构未破的位置。

加分点：

- 底部抬高，低点不再创新低。
- 修复上涨有量，回踩明显缩量。
- 价格重新站上趋势线后未有效跌破。

扣分点：

- 只是弱反弹，未形成右侧结构。
- 回踩重新跌回前低或平台下方。
- 左侧套牢压力过重且没有放量消化。

### 第四类：强趋势加速后的短线回踩

特征：

- 股价处于强主升或加速段。
- 短线回撤使 KDJ 回到低位。
- 回调缩量，价格仍守住短期趋势。
- 适合强趋势里的节奏性买点，但风险高于低位结构。

加分点：

- 强趋势清晰，均线陡峭上行。
- 回调量明显小于上攻量。
- 没有高位放量出货或连续长上影。

扣分点：

- 已严重远离均线，性价比下降。
- 高位放量滞涨或放量阴线。
- 回调已经跌破加速趋势。

## B2 经典图形

### 平行重炮

特征：

- 前后两次强阳或攻击 K 线形成呼应。
- 中间调整不破坏结构。
- 第二次攻击即 B2 日，最好放量且实体强。
- 调整阶段缩量，没有明显出货。

### 灾后重建

特征：

- 前期急跌、破坏或大幅波动后逐步修复。
- B1 出现在修复过程的低位拐点。
- B2 用强阳和量能确认修复有效。
- 成交量从恐慌释放转为上涨放量、回落缩量。

### 跃跃欲试

特征：

- 低位或平台内多次试盘、蓄势。
- 上方压力被反复测试，但结构没有走坏。
- B2 强阳带量向上确认。
- 试盘阶段不能连续放量失败。

## 砖型图经典图形

砖型图战法不是寻找低位安全垫，而是寻找走势转折点的爆发力。核心假设是：绿砖转红砖当日如果爆发力足够强，次日更容易延续这一段爆发，策略目标是吃到延续爆发力对应的短线涨幅。

砖型图经典图形分三种结构原型，三类没有强弱顺序：

### 定势 1：N 型起跳

特征：

- 前面已有一段向上试攻或修复，随后回踩形成绿砖。
- 回踩不破坏主要趋势，最好靠近黄白线或关键支撑。
- 连续绿砖之后出现首根有效红砖，形成 N 型第二段起跳。
- 红砖最好盖过前一根绿砖，说明新一轮买盘强度压过上一段调整压力。

### 定势 2：横盘起跳

特征：

- 股价长期横盘或窄幅震荡，黄白线逐渐靠近，波动被压缩。
- 绿砖调整后出现红砖，价格从横盘区间内或区间上沿启动。
- 最理想是转折点在黄白线之间，买点离白线越近越好。
- 红砖大但 K 线本身不宜跳空过度，避免变成已经透支的追高。

### 定势 3：上升波段延续

特征：

- 原趋势已经向上，短线回踩或震荡释放压力。
- 绿砖阶段属于上升途中的洗盘，而不是趋势破坏。
- 红砖转折出现在白线或黄白线附近，重新恢复上攻节奏。
- 成交量最好表现为上攻放量、回调缩量，转折日重新放量或至少不弱。

### 砖型图图形匹配的内部权重

`classic_pattern_match` 仍输出 0 到 5 分。对砖型图，建议先按 100 分制拆解，再换算为 0 到 5 分：

| 子项 | 权重 | 评分重点 |
| --- | --- | --- |
| 转折爆发力和砖 K 组合 | 35% | 绿砖转红砖是否明确，红砖是否足够大，是否盖过前一根绿砖；中长阳 K 线 + 大红砖、小阳线 + 大红砖都有概率优势，其他组合优势不明显。 |
| 转折点位置 | 25% | 绿转红位置是否在黄白线之间，是否靠近白线，是否仍处于可爆发区而不是远离均线后的高位追涨。 |
| 前置结构原型 | 20% | 是否符合 N 型起跳、横盘起跳、上升波段延续中的任一类；连续绿砖之后的首根强红砖加分更高。 |
| 单 K 质量和跳空约束 | 10% | 不能有跳空；理想 K 线是实体较小、上下影线短、红砖大，或实体中长阳且没有明显上影失败。 |
| 量价确认 | 10% | 上涨阶段放量、回调阶段缩量，转折日量能支持红砖爆发；下跌放量或最大量出现在阴线要扣分。 |

分数换算建议：

- 85 到 100 分：`classic_pattern_match = 5`
- 70 到 84 分：`classic_pattern_match = 4`
- 55 到 69 分：`classic_pattern_match = 3`
- 35 到 54 分：`classic_pattern_match = 2`
- 1 到 34 分：`classic_pattern_match = 1`
- 图表信息不足或完全无法判断：`classic_pattern_match = 0`

硬性上限：

- 出现明显跳空，`classic_pattern_match` 最高 1 分。
- 没有明确绿砖转红砖，最高 2 分。
- 红砖明显小于前一根绿砖，且不是连续绿砖后的有效反包，最高 3 分。
- 转折点已经远离白线、处于明显高位追涨，最高 3 分。
- 转折 K 线是长上影失败、放量冲高回落或阴线，最高 2 分。

如果后续允许不同策略使用不同总分权重，砖型图建议使用更偏向爆发力的五维权重：`trend_structure` 15%、`price_position` 25%、`volume_behavior` 20%、`previous_abnormal_move` 10%、`classic_pattern_match` 30%。其中 `classic_pattern_match` 承担砖型图核心优势判断，`previous_abnormal_move` 仍保持原始成交量异动含义，不混入经典图形分。

## 不加分和硬扣分

以下情况不属于经典图形加分：

- 只有单日上涨，没有前后结构。
- 图形普通，无法归入该策略声明的经典图形。
- 上涨无量，回调也不缩量。
- K 线结构与经典图形相似，但成交量不支持。

以下情况必须显著扣分：

- 放量大阴线。
- 最大成交量出现在下跌 K 线。
- 放量冲高回落。
- 连续放量滞涨。
- 已明显高位远离均线且上方空间不足。
